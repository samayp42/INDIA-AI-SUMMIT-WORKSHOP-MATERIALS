PART 1

Introduction to Pipecat

🐱

Pipecat Framework

Pipecat is an open-source Python framework for building voice and multimodal AI agents. It handles the complex orchestration of STT, LLM, and TTS services in real-time.

github.com/pipecat-ai/pipecat →

Why Pipecat?

Real-Time Processing

Handles streaming audio with minimal latency. Processes speech as you talk, not after.

Modular Components

Swap STT, LLM, or TTS providers easily. Use Whisper, OpenAI, Deepgram, ElevenLabs, and more.

Pipeline Architecture

Build processing pipelines by connecting components. Data flows through each stage automatically.

Local & Cloud

Run entirely on your AI PC with OpenVINO, or connect to cloud services for more power.

PART 3

Building a Voice Agent

Basic Pipeline Structure

voice_agent.py Python 
# Import Pipecat components
from pipecat.pipeline.pipeline import Pipeline
from pipecat.pipeline.task import PipelineTask
from pipecat.services.openai import OpenAILLMService
from pipecat.services.elevenlabs import ElevenLabsTTSService
from pipecat.transports.services.daily import DailyTransport

# Initialize services
llm = OpenAILLMService(
    api_key="your-api-key",
    model="gpt-4"
)

tts = ElevenLabsTTSService(
    api_key="your-api-key",
    voice_id="voice-id"
)

# Build the pipeline
pipeline = Pipeline([
    transport.input(),    # Audio in
    stt,                  # Speech to text
    llm,                  # AI processing
    tts,                  # Text to speech
    transport.output()    # Audio out
])

Setting the System Prompt

system_prompt.py Python 
# Define your AI's personality
messages = [
    {
        "role": "system",
        "content": """You are Cyber Sam, a fast-talking tech news anchor.
Keep responses under 2 sentences - you're on live TV!
Always ask a follow-up question to keep the interview moving.
Use phrases like 'Breaking news!' and 'Fascinating!'"""
    }
]

# Pass to LLM context
context = OpenAILLMContext(messages=messages)
context_aggregator = llm.create_context_aggregator(context)

Key Insight: The system prompt defines your agent's entire personality. Keep responses short for natural conversation flow!
