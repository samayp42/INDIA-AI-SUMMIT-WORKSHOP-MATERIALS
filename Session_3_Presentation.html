Key Concept

What is an AI Agent?

A chatbot can only think. An Agent can think AND act.

Chatbot (LLM)

Brain in a jar. Can answer questions but cannot do anything in the real world.

AI Agent

Brain + hands. Can reason, plan, and take actions via tools (APIs, databases, etc).

Our Finance Agent

LLM + Zerodha MCP. Reasons about finance, then fetches live data to answer you.

Key Concept

What is MCP?

Model Context Protocol — the universal adapter that lets AI talk to external services.

  • Open standard — Created by Anthropic, adopted industry-wide.
  • Plug & Play — Connect to APIs, databases, files. No custom code.
  • Secure — Data flows directly between your LLM and the API. No middleman.
// Think of MCP like USB-C
// One standard port. Many devices.

Deep Dive

The Agent Loop
(ReAct Pattern)

The Agent doesn't just answer. It Reasons → Acts → Observes → Repeats until it has the full picture.

🔁 ReAct = Reasoning + Acting. The LLM decides which tool to use, calls it, reads the result, and decides what to do next. 
// User asks a complex question:
"Compare RELIANCE and TCS — which is
more volatile this week?"

Step 1 — Reason:
  "I need prices for both stocks"

Step 2 — Act:
  → call get_quote("RELIANCE")
  → call get_quote("TCS")

Step 3 — Observe:
  "RELIANCE: ₹2,845 (±3.2%)"
  "TCS: ₹3,872 (±1.1%)"

Step 4 — Answer:
"RELIANCE is more volatile at ±3.2%
vs TCS at ±1.1% this week."
