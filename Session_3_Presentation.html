Concept

What is an Agent?

A Chatbot (LLM) is just a brain in a jar. It can think, but cannot act.

An Agent is a Brain with Hands (Tools).

Concept

The Agent Loop (ReAct)

Reason → Act → Observe.

The AI talks to itself before answering you.

User: "What's Apple's Price?"
Thought: "I need stock data."
Action: get_stock("AAPL")
Result: $185.50
The Mission

Scenario: Hedge Fund

You are a Quantitative Analyst.

The Task: Build an AI that can fetch LIVE stock data and perform technical analysis.

Tools: Python, YFinance API, MCP Server.

The Financial Analyst Bot

Step 1

Defining the Tool

We need to tell the AI how to get prices.

{ "name": "get_stock_price", "description": "Fetch current stock price for a ticker symbol", "parameters": { "type": "object", "properties": { "ticker": { "type": "string" } } } }

(This is the JSON Schema the LLM reads)

Step 2

Running the Analysis

Now, ask the Agent to do work.

"Compare the performance of Apple (AAPL) and Microsoft (MSFT) over the last 5 days. Which one is more volatile?"

Watch the 'Thoughts' panel to see it call the tool twice!

Step 3

Handling Errors

What if the API fails?

A good Agent sees the error and tries again or apologizes.

Action: get_stock("GOGLE") Error: Ticker not found. Thought: "Ah, I made a typo. It should be GOOGL." Action: get_stock("GOOGL")
Step 4

Investment Memo

Goal: Synthesis.

"Based on the prices you just fetched, write a brief investment memo for a conservative investor. Mention the P/E ratio if available."
Summary

MCP Architecture

  • Standardized: One protocol for all tools.
  • Secure: You control the API keys.
  • Local: The Agent logic runs on your NPU.
